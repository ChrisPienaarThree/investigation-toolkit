# Incident Investigation Toolkit (student edition)

Three incident-investigation tools for learners on Istec Training investigation courses. They run in the browser on
iPad, iPhone and Android devices, as well as on computers. There is nothing to install and no login.

**Open the toolkit:** https://chrispienaarthree.github.io/investigation-toolkit/

- Storyline Casebook: evidence register, ECFA+ storyline, ICAM, root causes, actions and report
- Tripod Beta Investigator: Tripod Beta trees with barriers, Immediate Cause, Precondition, Underlying Cause and BRFs
- RCA Fault Tree: cause-and-effect fault tree that tests each hypothesis against the evidence

Your work is kept only in the browser of the device you use. Nothing is sent to Istec Training or anyone else.
Save a copy of each case with the tool's save or download button.

All training cases are anonymised and fictional.

Generated from the master toolkit by `Source/_public_build/build_public.py`. Edit the masters, not these files.
